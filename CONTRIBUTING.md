# Contributing

Want to help improve the openSUSE membership application form? Bug reports, fixes and suggestions are welcome as issues or pull requests on the `ddemaio/connect2` repository.

The whole site is a single static `index.html` file. Keep changes simple and test the form in a browser before opening a pull request.

## Get notified of applications

Applications are sent to `membership-officials@lists.opensuse.org`. To receive them, subscribe to that list, or open a pull request adding your address to the `CONFIG.CC` array near the top of the `<script>` block in `index.html`.

Anything committed to the repository is public, so only add an address you are comfortable having visible on GitHub. Prefer a role alias over a personal mailbox.

## Something not working?

Open an issue on the repository and tag `@ddemaio` so it can be looked into.
